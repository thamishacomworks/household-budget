# 🏡 Household Budget

A simple web app to manage shared household money.

Add each person's contributions, record monthly bills and extra expenses, and see the remaining balance automatically.

### Features
- Monthly dashboard and transaction history
- Edit and delete contributions and expenses
- Backup and restore
- On-device data storage with IndexedDB
- Offline support after the first online visit

Your records stay in your browser and do not sync between devices. Back up your data regularly.
